# Ручной чеклист

Автоматические тесты не проверяют то, что зависит от живого человека,
микрофона и поведения чужих окон. Этот список нужно проходить перед выпуском
и после изменений в платформенном слое.

Отмечайте результат в копии файла, а не в репозитории.

## Плашка и трей

- [ ] Плашка появляется и не создаёт кнопку на панели задач.
- [ ] Щелчок по плашке не забирает фокус: курсор остаётся в поле ввода
      активного приложения (проверять в Cursor и в Блокноте).
- [ ] Плашка перетаскивается мышью, положение сохраняется после перезапуска.
- [ ] Правый щелчок по плашке открывает то же меню, что и трей.
- [ ] Полоска громкости реагирует на голос и гаснет в тишине.
- [ ] Меню трея: пауза прослушивания гасит системный индикатор микрофона.

## Несколько мониторов

- [ ] Плашка переносится на второй монитор и там остаётся после перезапуска.
- [ ] После отключения второго монитора плашка возвращается на основной,
      а не пропадает за пределами экрана.
- [ ] Проверить масштабы 100 %, 125 % и 150 % — плашка не размыта и не обрезана.

## Способы запуска

- [ ] Горячая клавиша запускает и останавливает запись в режиме `press_again`.
- [ ] В режиме `hold` запись идёт только пока клавиша удерживается.
- [ ] Короткий случайный щелчок боковой кнопкой не запускает распознавание.
- [ ] Боковая кнопка мыши продолжает работать в других приложениях
      (события не подавляются).
- [ ] Пункты меню трея «Начать» и «Остановить» работают и корректно гаснут.

## Распознавание

- [ ] Продиктовать 10-15 секунд обычной русской речи: текст осмысленный,
      слова не склеены.
- [ ] Продиктовать фразу с английскими терминами («открой файл `main.py`
      в Cursor»): проверить, что при движке Whisper термины записаны латиницей.
- [ ] Проверить время отклика: от остановки записи до текста.
- [ ] Отключить микрофон во время записи — приложение сообщает об ошибке
      и возвращается в рабочее состояние.

## Вставка

- [ ] Блокнот, Cursor, PowerShell, браузер — текст вставляется полностью.
- [ ] Окно, запущенное от администратора: вставка не проходит, но появляется
      понятное сообщение, а текст остаётся в буфере обмена.
- [ ] Полноэкранная игра: текст попадает в буфер обмена.
- [ ] Русская и английская раскладки: сочетание вставки срабатывает одинаково.

## Голосовая активация

- [ ] Включить фразу запуска: срабатывает с задержкой не больше секунды.
- [ ] Кулдаун гасит повторное срабатывание сразу после первого.
- [ ] Режим остановки «отдельная команда» и «повтор той же команды»
      действительно останавливают запись.
- [ ] Фоновый разговор или созвон не запускают запись слишком часто.
- [ ] Нагрузка в простое не превышает нескольких процентов одного ядра.

## Окно настроек

- [ ] Все восемь вкладок открываются, значения совпадают с файлом настроек.
- [ ] «Сбросить раздел» возвращает заводские значения только своего раздела.
- [ ] «Сбросить все настройки» не трогает инструкции и словарь замен.
- [ ] Смена микрофона на вкладке «Распознавание» применяется после сохранения.
- [ ] Смена пресета меняет состав моделей и сбрасывает кэш движков.
- [ ] Инструкции: правка, «Показать отличия», «Вернуть заводскую»
      и «Проверить на примере» работают без микрофона.
- [ ] Диагностика: все четыре проверки дают понятный ответ, а проверка вставки
      успевает дождаться переключения окна.
- [ ] Автозапуск включается и выключается, запись в реестре появляется и исчезает.

## История

- [ ] После обработки в истории появляется запись с режимом, длительностью
      и временем обработки.
- [ ] Копирование сырого, очищенного и итогового текста даёт разные результаты.
- [ ] «Вставить итоговый» отправляет текст в активное окно.
- [ ] Удаление записи и полная очистка работают.
- [ ] При лимите 50 после 60 запросов остаётся ровно 50 свежих записей.
- [ ] При лимите 0 файл `history.db` не создаётся.
- [ ] Аудиофайлов на диске не появляется ни при каких настройках.

## Перенос и установка

- [ ] Экспорт создаёт zip; внутри нет моделей и (без запроса) истории.
- [ ] Импорт на чистом профиле восстанавливает настройки, инструкции и словарь.
- [ ] Импорт чужого zip отклоняется понятным сообщением.
- [ ] Portable-архив запускается из распакованной папки, данные ложатся
      в `userdata` рядом с исполняемым файлом.
- [ ] Установщик ставит приложение без запроса UAC, ярлыки создаются.
- [ ] Деинсталлятор отдельно спрашивает про пользовательские данные и модели.
- [ ] Мастер первого запуска доводит чистую машину до рабочего состояния.

## Устойчивость

- [ ] Повреждённый файл настроек: приложение стартует на заводских значениях
      и сообщает об этом.
- [ ] Закрыть `llama-server` во время обработки: появляется сообщение,
      приложение продолжает работать.
- [ ] Нехватка видеопамяти: понятное сообщение, переход на меньшую модель.
- [ ] Второй запуск приложения: сообщает, что уже запущено, и завершается.
- [ ] Прерванная загрузка модели продолжается с того же места после повтора.
