# VoiceFlow

Локальное Windows-приложение для голосового ввода. Говорите свободным потоком
по-русски — приложение распознаёт речь, убирает слова-паразиты, при
необходимости переводит на английский или превращает поток мыслей в инструкцию
для AI-модели, кладёт результат в буфер обмена и вставляет в активное окно.

После первичной загрузки моделей приложение работает без интернета. Аудио
никуда не отправляется и на диск не пишется.

## Возможности

- Запуск горячей клавишей, боковой кнопкой мыши, из меню трея или голосовой
  командой, которую вы задаёте сами.
- Локальное распознавание русской речи: GigaAM для чистого русского,
  Whisper для смешанной русско-английской речи.
- Очистка текста: слова-паразиты, повторы, мычание, ложные начала.
- Перевод на английский и режим «Инструкция для AI» через локальную
  языковую модель.
- Небольшая плашка с состоянием и уровнем микрофона, не забирающая фокус.
- Локальная история результатов с ограничением по количеству записей.
- Окно настроек с восемью вкладками, редактором инструкций и диагностикой.

## Требования

- Windows 10 x64 или новее.
- Python 3.12 — ставится автоматически через `uv`, системный Python не трогается.
- Для быстрого режима — видеокарта NVIDIA с 6 ГБ памяти. Без неё работает
  облегчённый пресет на процессоре.

Место на диске зависит от пресета: около 1.5 ГБ для лёгкого, около 8 ГБ для
стандартного, около 15 ГБ для пресета «Качество».

## Установка для разработки

```powershell
# Установить uv, если его ещё нет
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

# Развернуть окружение одной командой
powershell -ExecutionPolicy Bypass -File scripts\install.ps1

# Вместе с нужными движками
powershell -ExecutionPolicy Bypass -File scripts\install.ps1 asr whisper
```

Доступные дополнения: `asr` (GigaAM и Silero VAD на процессоре), `asr-gpu`
(то же под CUDA), `whisper`, `wake-vosk` (голосовая активация), `translate`
(локальный Opus-MT).

Проверка окружения и путей:

```powershell
uv run python -m voiceflow --check
```

Запуск:

```powershell
uv run python -m voiceflow
```

## Модели

Модели не входят ни в репозиторий, ни в установщик: в `config/models.toml`
лежат только ссылки и контрольные суммы. При первом запуске откроется мастер —
он покажет состав выбранного пресета, объём загрузки и скачает недостающее,
продолжая прерванную загрузку с того же места.

Без графической оболочки то же делает скрипт:

```powershell
uv run python scripts\download_models.py --preset light
uv run python scripts\download_models.py --list
```

Для машины без интернета положите заранее скачанные файлы в одну папку и
нажмите «Взять из готовой папки» на вкладке «Модели»: имена должны совпадать
с именами из реестра.

## Сборка

```powershell
# Portable-архив: dist\VoiceFlow-portable.zip
powershell -ExecutionPolicy Bypass -File scripts\build_portable.ps1

# Установщик: installer_output\ (нужен Inno Setup 6)
powershell -ExecutionPolicy Bypass -File scripts\build_installer.ps1
```

Установщик ставит приложение в `%LOCALAPPDATA%\Programs\VoiceFlow` — без прав
администратора и без запроса UAC. Билд не подписан, поэтому при первом запуске
SmartScreen покажет предупреждение, а антивирус может насторожиться на
бутлоадер PyInstaller. Подпись сертификатом — отдельная задача.

## Проверки

```powershell
uv run ruff check src tests scripts
uv run mypy src/voiceflow/core
uv run pytest tests/unit tests/integration
```

Тесты с меткой `slow` требуют загруженных моделей и в CI пропускаются, с меткой
`gui` — поднимают Qt в offscreen-режиме и работают без графической сессии.
Ручной чеклист платформы: [docs/manual-tests.md](docs/manual-tests.md).

Хук `pre-commit` не пускает в репозиторий модели, аудио, пользовательские
данные и файлы больше 10 МБ:

```powershell
uv run pre-commit install
```

## Где лежат данные

Код и заводские значения — в папке приложения, всё пользовательское — в
профиле. Точные пути показывает команда `--check` и вкладка «Диагностика».

- Настройки, инструкции и словарь замен: `%APPDATA%\VoiceFlow`
- История, журналы, модели и кэш: `%LOCALAPPDATA%\VoiceFlow`

Portable-режим включается файлом `portable.txt` рядом с приложением: тогда все
данные лежат в подпапке `userdata` рядом с исполняемым файлом.

## Перенос на другой компьютер

Вкладка «Общие» → «Экспортировать настройки» собирает zip с настройками,
изменёнными инструкциями и словарём замен; история добавляется по запросу.
Модели в архив не попадают никогда — их загрузит мастер на новой машине.

Аудиоустройство подбирается по имени: если микрофон с таким названием не
найден, берётся системный по умолчанию и появляется уведомление.

## Устройство проекта

- `src/voiceflow/core` — ядро: не знает ни про Qt, ни про Windows, работает офлайн.
- `src/voiceflow/platform` — платформенный слой за интерфейсами из `base.py`.
- `src/voiceflow/ui` — Qt: плашка, трей, окно настроек, мастер моделей.
- `config` — заводские настройки, инструкции, реестр моделей.

Границы проверяются тестами: `tests/integration/test_core_isolation.py` падает,
если в ядро попадёт импорт Qt, Win32 или сетевой библиотеки без явного
разрешения.
